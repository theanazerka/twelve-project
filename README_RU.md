# Twelve

[English version](README.md)

Twelve — неофициальный клиент Telegram для iOS 6, созданный на базе официальных исходников Telegram для iOS. Внутреннее название проекта — **Twelvium**, название приложения — **Twelve**.

Цель проекта — сохранить возможность пользоваться Telegram на старых устройствах Apple и предоставить дополнительное оформление в стиле оригинальной версии Telegram для iOS 6.

> Проект не связан с Telegram Messenger и не поддерживается его разработчиками.

## Возможности

- Поддержка iOS 6.0 и новее
- Интерфейс для iPhone и iPad
- Включаемая классическая тема iOS 6
- Чаты, группы и каналы Telegram
- Медиафайлы, стикеры и голосовые сообщения
- Исправления совместимости с современной инфраструктурой Telegram
- Интерфейс и ресурсы, адаптированные для старых устройств

## Состояние проекта

Twelve находится в разработке. Некоторые современные функции Telegram могут отсутствовать или работать нестабильно, поскольку клиент основан на старой кодовой базе и запускается на операционной системе 2012 года.

Сообщения об ошибках и проверенные исправления приветствуются.

## Сборка

### Что потребуется

- macOS и совместимая версия Xcode
- SDK iOS 6.1 либо другой набор инструментов с поддержкой сборки для iOS 6
- Собственные Telegram API ID и API hash
- Сертификат Apple для установки на физическое устройство

### Порядок сборки

1. Клонируйте репозиторий вместе с сабмодулями:

   ```bash
   git clone --recursive https://github.com/theanazerka/twelve-project.git
   cd twelve-project
   ```

2. Создайте локальный файл конфигурации:

   ```bash
   cp config.h.example config.h
   ```

3. Укажите в `config.h` собственные Telegram API ID и API hash.

4. Откройте `Telegram.xcworkspace` в Xcode.

5. Выберите схему `Telegraph`, настройте идентификатор приложения и подпись.

6. Запустите сборку для устройства или симулятора.

Не публикуйте `config.h`, сертификаты подписи, provisioning profiles и другие приватные данные.

## Упаковка IPA

После того как Xcode соберёт `Telegram.app`, неподписанный IPA можно упаковать следующими командами:

```bash
mkdir -p Payload
cp -R /путь/до/Telegram.app Payload/
zip -r Twelve.ipa Payload
```

Подпись и установка выполняются отдельно.
